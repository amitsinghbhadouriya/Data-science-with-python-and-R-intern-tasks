# Task 04 — Dimensionality Reduction & Unsupervised Clustering

## Deliverable
`Dimensionality_Reduction_Unsupervised_Clustering.ipynb`

## What is implemented
- Feature standardization using `StandardScaler`
- PCA with explained-variance table
- PCA scree plot and cumulative explained-variance plot
- 2D and 3D PCA projections
- K-Means clustering
- Elbow Method using inertia
- Silhouette Score analysis for k=2..10
- DBSCAN clustering with noise detection
- Hierarchical/Agglomerative clustering
- 2D cluster visualizations
- Final algorithm comparison

## Dataset
The notebook uses scikit-learn's built-in Iris dataset, so no external CSV download is required.

## Run
Open the `.ipynb` file in VS Code/Jupyter and run all cells.

If packages are missing:
```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```
