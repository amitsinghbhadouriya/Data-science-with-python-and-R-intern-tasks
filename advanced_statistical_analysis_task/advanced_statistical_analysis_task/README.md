# Advanced Statistical Analysis & Hypothesis Testing

This repository contains the completed notebook for the Advanced Statistical Analysis & Hypothesis Testing task.

## Included analysis

- Shapiro–Wilk normality test
- Kolmogorov–Smirnov normality test
- Distribution histograms, boxplots and Q-Q plots
- Welch two-sample t-test
- Mann–Whitney U test
- 95% confidence intervals
- Cohen's d effect size
- One-way ANOVA
- Tukey HSD post-hoc analysis
- Levene variance-homogeneity test
- Two-way ANOVA with interaction
- Partial eta-squared effect sizes
- Statistical findings and conclusion

## Dataset

The notebook uses the Wine recognition dataset bundled with scikit-learn. No external CSV download is required.

## Run

```bash
pip install -r requirements.txt
jupyter notebook Advanced_Statistical_Analysis_Hypothesis_Testing.ipynb
```
